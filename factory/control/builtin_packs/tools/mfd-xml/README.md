# MFD → 江苏标准 XML（清单局部提取）

由逆向工程职能体基于已有样本、逆向笔记与江苏未来数据标准 XSD 开发，**没有现成转换器源码**。

## 它做什么

按已确认的 MFD 词素（`04 08 06` 单字节串 / `08 12 02` UTF-16LE 串 / `03 05` double /
`02 <tag>` 字段分隔符）扫描记录流，用局部文法识别「12 位清单编号 → 名称 → 单位 → 数值组」，
输出：

- `project.xml`：江苏标准的清单子集，只含 XSD 必填字段齐全的记录。
- `extraction_report.json`：**每一条**识别到的记录，带文件偏移、已解析字段和缺失字段。

## 它明确不做什么

- 不做整文件分帧，不声称无损转换。容器只带子节点个数、不带字节长度，整体分帧尚未打通。
- 不补零、不取默认值、不从参考 XML 回填业务值。缺 XSD 必填字段的记录不进 XML。
- 只要有记录不完整，整次调用以 `incomplete_extraction` 失败返回；候选 XML 仍可下载，但不标记为已验证。

## 一处声明过的归一

单价/合价按 2 位小数 ROUND_HALF_UP 归一（造价金额以分为单位，MFD 里存的是累加后的 double）。
原始 double 的最短往返表示同时写进 `extraction_report.json`，可随时核对。工程量不归一。

## 样本与隐私

`fixtures/` 全部是**合成**样本，由 `fixtures/make_fixtures.py` 按已确认词素生成，业务值虚构。
真实工程样本不进仓库；对真实样本的核对结论见 `docs/mfd/mfd-xml-extraction-report.md`。
