## 契约: T02 React 前端脚手架搭建

### 我的输入（依赖项）
- 项目根目录：`/home/ubuntu/workspace/unmanned-factory/`
- Node.js / npm 可用（系统已装）
- 需要在根目录新建 `frontend/` 子目录

### 我的输出（交付物）
- 目录：`frontend/`（独立的 React 项目）
- 文件清单：
  - `frontend/package.json`（包含 react、react-router-dom、axios、tailwindcss）
  - `frontend/vite.config.ts`（配置开发代理：`/api/*` → `http://127.0.0.1:8788/api/*`）
  - `frontend/tailwind.config.js`
  - `frontend/postcss.config.js`
  - `frontend/tsconfig.json`
  - `frontend/index.html`
  - `frontend/src/main.tsx`（入口文件，路由根挂载）
  - `frontend/src/App.tsx`（空壳，占位，只渲染 `<RouterProvider router={router} />`）
  - `frontend/src/index.css`（Tailwind 指令）
  - `frontend/.gitignore`（node_modules、dist、.env.local）

### 完成标准
- [ ] `cd frontend && npm install` 能成功安装依赖
- [ ] `npm run dev` 能启动开发服务器（默认 `http://localhost:5173`）
- [ ] 浏览器打开 `http://localhost:5173` 显示 React 默认页面（不报错）
- [ ] Vite 代理配置正确：前端请求 `/api/tasks` 会转发到 `http://127.0.0.1:8788/api/tasks`
- [ ] Tailwind 已生效（在 `App.tsx` 里写一个 `<div className="text-blue-500">Test</div>` 能看到蓝色文字）
- [ ] 通过以下验证：

```bash
# tests/test_frontend_scaffold.sh
cd frontend
npm install
npm run build  # 能打包成功
test -d dist   # dist/ 目录存在
test -f dist/index.html  # 有入口文件
```

### 不包含（边界说明）
- 不实现任何业务页面（TaskList/TaskDetail/Stats 留给 T03/T04/T05）
- 不配置 UI 组件库（shadcn/Ant Design 等，后续任务按需引入）
- 不写测试框架配置（Vitest/Jest，非核心需求）
- `App.tsx` 只是空壳路由容器，不要写任何实际组件

### 技术约束
- 脚手架工具：`npm create vite@latest frontend -- --template react-ts`
- React 版本：18+
- 路由：react-router-dom v6+
- HTTP 客户端：axios
- 样式：TailwindCSS v3+
- 开发服务器端口：5173（Vite 默认）
- 后端 API 地址：`http://127.0.0.1:8788`（开发时通过 Vite proxy，生产时走 Caddy 同源）

### Vite proxy 配置示例

```typescript
// vite.config.ts
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'

export default defineConfig({
  plugins: [react()],
  server: {
    proxy: {
      '/api': {
        target: 'http://127.0.0.1:8788',
        changeOrigin: true,
      },
    },
  },
})
```
