## 契约: T05 统计页

### 我的输入（依赖项）
- `GET /api/stats`（T01 提供，响应形状见 `contracts/api-shape.md`）
- `frontend/` 脚手架（T02 提供）
- `frontend/src/types.ts` 的 `Stats` 类型
- `frontend/src/hooks/usePolling.ts`（T04 提供，签名同 T03 契约所述）

### 我的输出（交付物）
- `frontend/src/pages/Stats.tsx`
- `frontend/src/components/StatCard.tsx`（大数字卡片）

### 页面结构

第一排四张大数字卡：

```
  总任务数        总花费          已合并         平均每任务
     4          $29.12            1             $7.28
```

第二排两个分布条（纯 CSS 横向堆叠条，**不引图表库**）：

```
按结局分布
  merged     ██                    1
  reworked   ████████████          6
  escalated  ██████                3

按队列状态
  done       ██                    1
  needs-human████                  2
  inbox                            0
```

### 配色
- 花费用醒目色（`text-emerald-600`，大字号 `text-4xl font-bold`）
- merged 绿、reworked 黄、escalated 橙、blocked 红（与 T03/T04 一致）
- 分布条用 `bg-*-400`，宽度按比例算 `width: ${pct}%`

### 轮询要求
- 每 60 秒重拉 `GET /api/stats`
- 显示「上次更新」时间戳
- 失败保留旧数据

### 完成标准
- [ ] 四张大数字卡正确渲染，金额保留两位小数
- [ ] 两个分布条按比例显示，总数为 0 时不出现除零错误（显示「暂无数据」）
- [ ] 60 秒自动刷新
- [ ] `npx tsc --noEmit` 无错误，`npm run build` 成功

### 验证命令

```bash
cd frontend
npx tsc --noEmit
npm run build
```

### 不包含（边界说明）
- **不引图表库**（echarts/recharts/chart.js 一律不要，纯 CSS 条形图足够）
- 不做时间范围筛选
- 不做趋势图（需要按时间聚合的 API，当前没有）
- 不实现另外两个页面

### 技术约束
- React 18 函数组件 + hooks
- TypeScript 严格模式，不许 `any`
- TailwindCSS 手写，零图表依赖
- axios 请求
- 金额格式化用 `Intl.NumberFormat`（`style: 'currency', currency: 'USD'`）
