## 契约: T03 任务列表页（首页）

### 我的输入（依赖项）
- `GET /api/tasks`（T01 提供，响应形状见 `contracts/api-shape.md`）
- `frontend/` 脚手架（T02 提供）
- `frontend/src/types.ts`（`TaskBuckets` / `TaskSummary` / `QueueState`）
- `frontend/src/hooks/usePolling.ts`（T04 提供；若尚未存在则自己实现同名 hook，
  签名必须是 `usePolling<T>(fetcher: () => Promise<T>, intervalMs: number)`
  返回 `{ data, error, lastUpdated, loading }`，两边实现要能互换）

### 我的输出（交付物）
- `frontend/src/pages/TaskList.tsx`
- `frontend/src/components/TaskCard.tsx`
- `frontend/src/components/StateBadge.tsx`（状态徽章，T04 也可复用）

### 页面结构

五列看板（或五个纵向分组，窄屏时堆叠）：

```
inbox(0)      running(1)      done(1)       needs-human(2)   blocked(0)
─────────     ──────────      ────────      ──────────────   ─────────
              [T-xxx  ⟳]      [T-yyy ✓]     [T-zzz ⚠]
                              $2.91 · 9轮    C级闸门拦下
```

每张任务卡片显示：
- `task_id`（等宽字体，可点击 → 跳 `/task/:task_id`）
- `prompt_preview`（两行截断，`line-clamp-2`）
- `checks_count`（「1 条判据」）
- `mtime`（相对时间，如「3 小时前」）
- done / needs_human 桶额外显示：`total_cost_usd`、`attempts_count`、`resolution` 徽章

### 状态配色（与 T04 保持一致）
- inbox：灰 `bg-slate-100 text-slate-600`
- running：蓝 + 脉冲动画 `bg-blue-50 text-blue-700 animate-pulse`
- done：绿 `bg-emerald-50 text-emerald-700`
- needs_human：橙 `bg-amber-50 text-amber-700`
- blocked：红 `bg-red-50 text-red-700`

### 轮询要求
- 每 60 秒重拉 `GET /api/tasks`
- 顶部显示「上次更新：HH:MM:SS」+ 手动刷新按钮
- 轮询失败保留旧数据，只在顶部显示一条警告条
- 组件卸载时清理定时器

### 完成标准
- [ ] 五个状态桶全部渲染，空桶显示「暂无任务」而不是留白
- [ ] 点击卡片能跳到 `/task/:task_id`
- [ ] 60 秒自动刷新，且有「上次更新」时间戳
- [ ] running 桶的卡片有脉冲动画
- [ ] 窄屏（<768px）时五列堆叠成单列，不横向滚动
- [ ] `npx tsc --noEmit` 无错误，`npm run build` 成功

### 验证命令

```bash
cd frontend
npx tsc --noEmit
npm run build
```

### 不包含（边界说明）
- 不实现详情页（T04）和统计页（T05）
- 不做搜索/筛选/排序（后续需求，不在本次范围）
- 不做写操作（新建任务、删除任务的按钮一律不做）
- 不引入 UI 组件库

### 技术约束
- React 18 函数组件 + hooks
- TypeScript 严格模式，不许 `any`
- TailwindCSS 手写样式
- axios 请求
- 相对时间自己写（`Intl.RelativeTimeFormat`），不引 dayjs
