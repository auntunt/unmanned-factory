## 契约: T01 后端 API 层实现

### 我的输入（依赖项）
- 已有 `audit.db` 数据库文件路径：`/home/ubuntu/factory-data/audit.db`
- 已有队列目录：`/home/ubuntu/factory-data/queue/`
- 依赖：标准库 `http.server`（不引入新 web 框架）
- 已有 `factory.audit.store.AuditStore`（可复用）
- 已有 `factory.backlog.store`（队列常量 INBOX/RUNNING/DONE/...）
- 表结构：
  ```sql
  task_attempt (id, task_id, attempt_no, model, cost_usd, tokens_in, tokens_out, 
                wall_clock_ms, resolution, commit, oracle_class, class_reason, ...)
  supervisor_verdict (id, attempt_id, role, verdict, claims, ...)
  ```

### 我的输出（交付物）
- 文件：`factory/api.py`
- 导出函数：`serve_api(db: str | Path, queue: str | Path, *, port: int = 8788) -> None`
- 三个路由（用 `http.server.ThreadingHTTPServer` + `BaseHTTPRequestHandler`）：
  - `GET /api/tasks` → `{"inbox": [...], "running": [...], ...}`
  - `GET /api/task/<task_id>` → `{"task_id": "...", "prompt": "...", "attempts": [...]}`
  - `GET /api/stats` → `{"total_tasks": N, "total_cost_usd": X, ...}`

### 完成标准
- [ ] 三个端点全部返回 200 + 正确 JSON
- [ ] CORS 头：每个响应都带 `Access-Control-Allow-Origin: *`（前端跨端口调用要用）
- [ ] 错误处理：task_id 不存在返回 404 + `{"error": "..."}`
- [ ] 队列目录不存在时抛异常而不是静默返回空（沿用 dashboard 的 `_scan_queue` 约定）
- [ ] 纯函数与 HTTP 层分离：数据组装写成可直接调用的函数，测试不必起服务器
- [ ] 通过以下单元测试（用 stdlib，项目没有 requests 依赖）：

```python
# tests/test_api.py
from pathlib import Path
from factory.api import list_tasks, task_detail, global_stats

def test_list_tasks(tmp_path):
    """list_tasks 返回五个状态桶"""
    for d in ("inbox", "running", "done", "needs-human", "blocked"):
        (tmp_path / d).mkdir()
    out = list_tasks(tmp_path)
    assert set(out) == {"inbox", "running", "done", "needs_human", "blocked"}

def test_task_detail_has_attempts(audit_db):
    """task_detail 带出轮次列表，按 attempt_no 升序"""
    out = task_detail(audit_db, QUEUE, "T-console-empty-hint")
    assert out["task_id"] == "T-console-empty-hint"
    nos = [a["attempt_no"] for a in out["attempts"]]
    assert nos == sorted(nos)

def test_task_detail_missing_returns_none(audit_db):
    """不存在的 task_id 返回 None，由 HTTP 层转 404"""
    assert task_detail(audit_db, QUEUE, "T-nope") is None

def test_global_stats(audit_db):
    """global_stats 汇总任务数与花费"""
    out = global_stats(audit_db, QUEUE)
    assert out["total_tasks"] >= 0
    assert out["total_cost_usd"] >= 0
```

### 不包含（边界说明）
- 不实现 POST/PUT/DELETE（只读 API）
- 不做认证/鉴权（开发阶段无需）
- 不实现实时推送（前端用轮询）
- 不修改 `factory/cli.py` 的主入口（只提供路由注册函数）

### 技术约束
- 语言：Python 3.11+
- HTTP：标准库 `http.server`（`ThreadingHTTPServer` + `BaseHTTPRequestHandler`）
  项目当前生产依赖只有 SQLAlchemy 和 PyYAML，**不要为一个只读 API 引入 web 框架**
  （现有 `factory/dashboard.py` 就是这个取舍，照它的模式写）
- 数据库：复用 `factory.audit.store.AuditStore`，或 sqlite3 标准库
- YAML 解析：PyYAML（已有依赖）
- 返回：`Content-Type: application/json`，`json.dumps(..., ensure_ascii=False)`
- 绑定 `127.0.0.1`，不提供 `--host` 参数（同 dashboard：外部访问走 Caddy 反代）

### 调用示例

```python
# factory/cli.py 里注册一个 api 子命令
from factory.api import serve_api

serve_api(
    db="/home/ubuntu/factory-data/audit.db",
    queue="/home/ubuntu/factory-data/queue",
    port=8788,
)
```
