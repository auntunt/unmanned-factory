# 无人工厂：以职能体为入口的个人工作台

设计修订：2026-09-09，Astra。第二版取代上一版“垂直智能体工作室”的平台化首版范围；核心闭环已由 Luna 实现并经 Astra 本地验收。具体完成项与保留边界见 [实现与验收记录](IMPLEMENTATION-STATUS.md)。

## 产品定位

这是可定制的个人 Agent 工作台。用户先选择擅长某类工作的职能体，直接对话、提供项目和资料，得到可查看和使用的成果。用户也能通过对话教会它新的方法，使下一次任务沿用。

核心只有：**一个持续工作的 loop + 可保存的专业配置 + 项目上下文 + 可使用的成果。**

职能体是用户委派工作的第一入口，例如旧项目维护员、工业格式转换维护员。它默认运行在同一个执行底座上，不意味着每个职能体都要启动一组独立 Agent。

## 两个主要动作

- **让它做事**：选职能体 → 说需求、放资料 → 自动关联或建立项目工作区 → 执行与验证 → 预览、下载、按需发布。
- **教它做事**：进入该职能体的维护对话 → 丢入 Skill、Prompt 或口语补充 → 模型整理更新并保存草稿 → 看清变化 → 应用到后续任务。

“新建职能体”同样通过对话完成。Skill 素材、模型设置、版本历史放在职能体内部按需展开，不要求用户先操作一套后台管理流程。

## 首版完成标准

用户能从职能体入口完成一次真实任务并取得成果；能用维护对话加入 Skill 和一句口语要求，查看整理结果并应用；新任务采用更新，旧任务保持原配置；模型可按职能体分别设置，需要时覆盖分析、执行、验证；中断可恢复，失败说明原因。首版不要求先建完通用评测中心、编排编辑器或多 Agent 团队系统。
