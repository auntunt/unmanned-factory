# 工作区与职能体交互复查（2026-09-09）

目标：先建立工作区，再描述需求；用户应直接领取成果，维护配置有明确入口。

修正：空工作区直接显示需求输入；简短非空口语描述进入规划，空白仍拒绝；工程总览面包屑修正；新建工作区链接直接打开创建表单。已绑定会话明确锁定项目，新对话可重新选择；隐藏系统仓库标识。任务与维护分别保留未发送的文字及附件，同模式点击不清空会话。模型在任务模式只读，通过维护入口修改。维护历史优先恢复最新任务终态，隐藏已完成任务的旧排队消息。成果页优先查看下载，GitHub 发布收进可选区域；费用尚未返回不再覆盖已验证成果的领取指引，费用记录仍保留。

验证：前端构建及 127 项测试通过。后端工作区、职能体路由、交付文件相关 30 项回归通过。浏览器在隔离本地环境实际验证空工作区、两字需求按钮、绑定项目锁定、模型只读与维护切换、草稿隔离恢复、维护完成状态、已验证成果页及 RESULT.md 预览。未在生产创建测试账号或触发付费模型运行。
