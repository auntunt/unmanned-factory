## 五、精确缺口清单（需补齐才能闭合真实转换环）

1. **转换器源码**：`mfd_converter` Python 包（reader.py/writer.py/fields.py/crypt.py）
   或 `mfd-ng` 的 Go 严格解析器。目前只有目标文档描述，代码不在本机，无法复用或修复。
2. **lxml**（可选）：装上后保真工具可做完整 XSD 内容模型校验（序列/出现次数），
   现仅做元素/属性词表校验。
3. **字节级分帧规则的落地实现**：逆向总结显示分帧仅完成个位数百分比（首次失败卡在
   头 3–24 KB），费用明细/工料机/单价构成等字段的稳定提取路径尚未在代码中实现。
4. **多样本参考对**：目前只核对了 2.mfd 一对；闻达府/南京建邺区等大文件的 mfd+参考 XML
   未提供，无法回归大文件元数据丢失（目标 P0#3）与安装工程残缺（P0#4）。
