# 真实浏览器截图说明

均来自**可丢弃的本地实例**（临时 SQLite，端口 18931，真实服务与真实写入），
不是预览夹具，也未连接正式服务器。脚本见交接文档「截图环境」一节。

截图在本次会话的浏览器面板中逐张确认，要点如下（对应验收 #3 #4 #5）：

1. `目录页（桌面）` —— 每卡：名称、用途、主按钮「开始对话」、弱入口「管理职能体」、
   「⋯」菜单；左侧导航没有与「职能体」并列的「能力库」。
2. `⋯ 菜单展开` —— 菜单项「编辑名称与用途」，role=menuitem。
3. `管理页` —— 面包屑「职能体 › 会议纪要助手 › 管理职能体」；基本信息 / 工作规范 /
   已挂靠工具 / 添加能力 四个区块；单一外框，正文内没有第二套「你的职能体」目录。
4. `改名即时生效` —— 保存后区块标题与面包屑同时变为新名（未刷新）。
5. `添加能力三来源` —— 上传包 / 团队已有能力 / 开发成果，一次只展开一个。
6. `目录页（375×812 窄屏）` —— 卡片堆叠，主按钮与「管理职能体」均可达。

浏览器内另行核实（非截图，JS 读取真实 DOM）：
- Esc 关闭「⋯」菜单，焦点归还触发按钮，`aria-expanded=false`。
- `/ability-center?tab=packs`、`/modules?selected=abc` 旧链接可达，查询参数保留，
  选中态归「职能体」，无并列页签。
- `/agents/:id?mode=maintain` 旧深链接仍进管理页。
