## 硬性约束
1. **不新增 HTTP 配置端点**，不绕过既有校验：对话工具必须调用上面这些现成方法，不得复制一份校验或直接写库。
2. **admin 身份校验**：对话工具执行前必须校验发起者 role == admin，非 admin 调用返回结构化拒绝（不是静默失败，也不是假成功）。当前 `conversation_tools.py` 的工具不检查角色——这是你要补的。
3. **密钥不进模型**：工具入参不接收密钥原文。密钥由服务端既有存储承担，模型侧只传引用/别名/用途。如果某个配置项**必须**有密钥才能完成，工具要返回"需要通过密钥字段提供"的结构化缺口，**不得**接受自然文本里的密钥来凑功能。
4. **不假成功**：连接检查失败就返回失败与具体缺口，不返回乐观文案。
