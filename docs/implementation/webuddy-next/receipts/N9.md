## MFD 口径改动

文件：`packs/mfd-xml-conversion/pack.json:4`

**改前**：
> 把江苏未来计价软件的 MFD 项目文件无损转换为江苏标准 XML：以官方 XSD 和可信参考 XML 为准，先做结构/数量覆盖、再按可靠标识对齐做字段值保真，用真实样本证明，不靠 mock 宣称成功。对旧 XML 的差异分析不等于对该 MFD 的成功转换；没有转换器就没有闭环。

**改后**：
> 从江苏未来计价软件的 MFD 项目文件中局部提取清单记录（编号、名称、单位、工程量、单价、合价）并生成江苏标准 XML 的清单子集：以官方 XSD 和可信参考 XML 为准，用真实样本证明，不靠 mock 宣称成功。这是清单局部提取，不是整文件无损转换；缺少 XSD 必填字段的记录一律判为不完整。

只改措辞字段，不改工具行为。与工具层 7 处「局部提取」口径一致。
