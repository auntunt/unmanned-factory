## 字段出现的响应
| 接口 | 方法 | 角色 | 包含 service_url |
|---|---|---|---|
| `/api/v2/deploy-targets` | GET | admin | 是（列表每条） |
| `/api/v2/deploy-targets/{tid}` | GET | admin | 是 |
| `/api/v2/deploy-targets` | POST | admin | 是（创建返回） |
| `/api/v2/deploy-targets/{tid}` | PUT | admin | 是（更新返回） |
| `/api/v2/projects/{pid}/deploy-targets` | GET | admin/member | 是（available 数组的 snapshot） |

member 通过项目绑定接口的 `available` 数组只能看到 `id`、`name`、`revision`、`service_url`，看不到 `host`、`user`、`port`、`commands`、`host_fingerprint`、`public_key`、`public_fingerprint`。

## URL 校验
- 接受 `http://` 和 `https://`
- 拒绝 `javascript:`、`data:`、`ftp:`、`file:`、相对路径
- 空字符串表示未配置，合法
