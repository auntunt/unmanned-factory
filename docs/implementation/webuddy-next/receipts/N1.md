## 需要主会话接线
1. **App.tsx 路由接入**：`RuntimeReadiness` 组件已创建，但 `App.tsx` 在主会话保留文件列表中。需要为 member 角色添加路由，例如：
   ```tsx
   import RuntimeReadiness from './workbench/RuntimeReadiness'
   // 在 Routes 中为非 admin 添加：
   {!isAdmin && <Route path="settings/runtime" element={<RuntimeReadiness {...pageProps} />} />}
   ```
   或者换一个 member 可见的路径（如 `/status`），取决于产品决策。
2. **Workbench.tsx 导航**：当前 member 看不到"运行配置"导航入口（`visibleSecondary` 为空）。如果希望 member 能看到一个入口通向 RuntimeReadiness，需要在 Workbench.tsx 中为 member 也显示一个导航项（可改标签为"运行状态"以区分）。Workbench.tsx 在保留列表中。

## 未验证项
- 端到端集成（需要真实登录 member 用户后打开 /settings/runtime 观察前端行为）——取决于主会话接线 App.tsx 路由。
