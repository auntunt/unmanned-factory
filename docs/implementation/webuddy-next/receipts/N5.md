## 三状态分别呈现

SessionSkillPanel 中每个 Skill 条目显示三个独立徽章：
1. **导入结果** — `imported` → "已导入" / `rejected` → "导入失败：{原因}"
2. **依赖状态** — `ready` → "依赖就绪" / `missing` → "需要管理员补齐：{依赖列表}" / `unknown` → "依赖状态未知"
3. **执行结果** — `true` → "最近执行成功" / `false` → "最近执行失败" / `null` → "尚未执行"

三者**不合并成一个"已启用"**。
