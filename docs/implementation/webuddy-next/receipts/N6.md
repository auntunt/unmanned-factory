## 「缺记录」的具体表示

- **后端**：`status: "no_record"`，`items: []`。不用空数组 + `"available"` 表示，不用 `null`，不用空字符串。
- **前端**：显示文案 `缺记录——该运行未记录此类信息，无法展示。`，通过 `data-testid="loaded-no-record"` / `data-testid="invoked-no-record"` 可测。
- **判定规则**：
  - 有 `module_snapshot` 或 `session_skill_snapshot` 键（即使值为空列表）→ status=available（现代 run）
  - 两个键都不存在 → loaded.status=no_record
  - 有 tool.call 事件 → invoked.status=available
  - 无 tool.call 且 loaded 已是 no_record → invoked.status=no_record（旧 run）
  - 无 tool.call 但 loaded 是 available → invoked.status=available（现代 run 只是没调用工具）
