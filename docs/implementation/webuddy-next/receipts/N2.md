## 变异验证

### 变异 1：去掉 admin 角色校验
- 红：member 调用 `update_runtime_config` 返回 `status: ok`（不是 rejected）→ 测试断言 `status == rejected` 失败
- 绿：恢复校验后 member 调用返回 `status: rejected, code: admin_required`

### 变异 3：去掉密钥扫描
- 红：admin 传入 `sk-ant-api03-*` 模型名后 `status: ok`（不是 rejected）→ 测试断言 `code == secret_detected` 失败
- 绿：恢复扫描后返回 `status: rejected, code: secret_detected`

## 需要主会话接线的点

   - 文件：`factory/control/agent_routes.py:366`
   - 改为：`conversation_binding=_ct.binding_for(store, cid, actor(request)['id'], actor_role=actor(request).get('role'))`

2. **`providers.py` 无需改动**：`TOOL_NAMES` 已自动包含 admin 工具名，`allowed()` 函数通过 `tool_name in _conv_tools.TOOL_NAMES` 匹配，新工具自动被允许。
