# 从成果页发布到 GitHub

成果页将 GitHub 入口与 ZIP 下载并列展示。是否已经配置服务器发布凭据、项目是否已经绑定仓库、成果是否已经上传，是三个独立状态。

管理员可选择可写的已有仓库，或在当前凭据所属个人账号下创建私有仓库。页面不收集或返回密钥。没有配置发布凭据时显示原因；普通成员仍可查看和下载已有成果。

首次上传到空仓库会把验收提交发布到基础分支，返回仓库链接，不声称创建了 PR。已有相关历史的仓库继续使用交付分支和 PR；没有共同历史的非空仓库不会被强行覆盖。已经存在完全相同的基础分支提交时，重试只确认发布结果。

项目绑定使用独立的版本检查与审计，不开放普通项目设置接口任意修改仓库。发布失败保留本地成果；创建仓库成功但后续失败时，重试使用已记录的创建结果，不重复创建。

服务器凭据通过现有外部环境文件提供，不进入代码库、模型工作区、前端响应或运行日志。已经出现在聊天中的密钥应当撤销更换。
