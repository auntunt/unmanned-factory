# 可组合工作台 · 2026-09-10

目标：保留六环看板、原有职能体、Skill、项目和版本记录；以独立能力模块补充固定职能体预设。

## 能力模块

风格、业务知识、工作方法、交付规范分别创建和版本化。每个项目最多12个模块，一种界面风格，累计指导文本不超过40000字符。保存组合固定所选版本；编辑模块产生新版本，项目需重新添加才升级。任务启动保存快照；继续和重试使用原快照。新的反馈任务使用项目当时的组合。模块指导进入规划、连续/分任务执行与独立验收，不赋予工具权限或覆盖用户需求。

保留原有职能体绑定。现有上传 Skill 仍由原职能体管理；本次模块支持文本内容，不把 ZIP 插件、运行时工具安装和凭据授权混为一谈。修改模块与项目组合沿用管理员权限；成员可查看模块库。内置样例只有通用风格/验证/交付方法，领域知识必须由团队提供。

接口：`/api/v4/modules`（GET/POST）、`/api/v4/modules/{id}`（PUT）、`/api/v4/projects/{id}/modules`（GET/PUT）。写操作要求登录、Origin 和 CSRF；更新使用版本冲突保护。存储新增两张表，旧数据无需破坏性迁移。
