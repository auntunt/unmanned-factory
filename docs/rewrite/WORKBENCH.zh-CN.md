# 全新工作台与 Agent 运行环境

这轮将主界面替换为独立工作台，并补齐真实运行所需的 SDK 安装、诊断、模型分工配置及部署流程。Astra 负责架构与复杂边界审查，Luna 分别执行工作台、任务详情、环境管理、安装脚本与专项测试，主代理完成集成和提交。

## 操作路径

| 页面 | 可以做什么 |
| --- | --- |
| 工作台 | 查看需要回复或确认的需求、正在执行的任务、最近交付；数据来自实际运行 |
| 项目 | 登记已有 Git 仓库，配置可信检查、基线、预算和 Issue 自动化策略 |
| 项目详情 | 提交需求、查看交付记录、维护项目档案与知识、建立代码索引、搜索源码、导入团队文档 |
| 任务详情 | 回答澄清、确认计划版本、切换任务列表和依赖图、查看问答、检查和 Git 提交证据、发布 PR |
| 运行配置 | 查看三家执行工具与配套程序安装状态，保存四个模型角色与限制，主动测试连接 |

界面采用深色侧栏、浅色工作区与路由懒加载。移动端提供折叠菜单；本轮没有可用浏览器运行时，手机点选和视觉验收仍需在部署后完成，不能以构建通过代替。

## 为什么此前部署后看不到 Agent 环境

现有执行方式由 `factory-web` 在有任务时启动 SDK 子进程，并不要求一个空闲时始终存在的 Agent daemon。但 SDK 是 Python 的可选依赖，普通安装不包含它们；后续普通 `uv run` 的依赖同步也可能移除已装的 extras。旧部署样例主要服务于旧引擎，不能保证新版执行环境完整。

更新流程安装全部 SDK 和其配套运行时，服务直接使用同一 `.venv/bin/factory-web`。诊断按包、可导入性、配套可执行程序、认证线索与真实连接测试分别报告。找到认证文件或环境变量，只表示存在配置线索，不代表账号、模型授权及网络已经验证。

SDK 接入依据：[Codex SDK 官方文档](https://developers.openai.com/codex/codex-sdk)、[Claude Agent SDK 官方文档](https://code.claude.com/docs/en/agent-sdk/overview)、[DeepSeek Harness SDK 包说明](https://pypi.org/project/deepseek-harness-sdk/)。锁定版本以 `uv.lock` 为准。

## 模型分工与成本

配置规划、简单任务、常规任务、困难任务四个角色，使用账号实际可用的执行工具和模型 ID。本次开发使用的 Astra/Luna 名称不会自动成为部署账号的有效模型 ID。

每次规划会冻结配置版本、模型映射和执行限制，写入审计与导出记录。修改运行设置只影响之后生成的计划；旧计划要采用新设置，需补充需求并重新规划。DSH 暂无适配器已验证的只读能力，不能用于规划或只读连接测试。

连接测试只在用户点击后运行固定短请求，可能计费；工作目录是独立临时目录。读取诊断、保存配置和打开面板不会自动调用模型。

费用未知默认停止派发下一批任务。若操作者明确选择按执行限制继续，系统会继续依赖任务，但受整体执行超时、任务数和并发数约束，保留费用未知标记，并禁止自动发布。执行层的 Git 子命令共享剩余时限，最终检查超时不会返回成功；底层本地文件检查须等待当前系统调用返回后才能报告超时。已知费用小计和未知总额分别保存；美元预算是已报告费用的停止阈值，无法保证供应商侧费用硬封顶。

## 项目设置与工程留痕

项目设置有版本冲突检测和不可改写的审计记录；存在规划、执行、等待确认或待交付任务时暂不能修改，避免审核标准在执行过程中漂移。仓库与工作区登记后不可直接改指向。可明确放弃待交付任务后修改设置，原日志和工作树继续保留。

需求、计划、公开助手消息、工具事件、检查和提交证据仍以事件保存并投影为问答；配置快照可随工程记录导出。项目代理保存稳定档案、经审核知识、固定提交的代码图和已核验合并事实，后续 Issue 可以检索这些上下文。它目前是可检索的工程记忆，尚不是独立常驻的自治进程。

## 部署与尚未验证的部分

使用 [部署说明](../../deploy/README.md) 与 [Hermes 交接](../../deploy/HERMES-HANDOFF.md)。Hermes 可以在服务器上核对环境、帮助配置真实账号，并更新已有服务；它没有被伪装为第四种 SDK。Hermes 的非交互调用依据 [官方 CLI 文档](https://hermes-agent.nousresearch.com/docs/user-guide/cli)，执行前仍核对服务器已安装版本的帮助。

本轮执行环境向服务器 SSH 连接返回 `Network is unreachable`，尚未进入密钥认证。因此没有声称已在服务器安装、重启服务或完成公网验收。提交包含可执行更新器和明确交接；真实付费模型任务、GitHub 账号发布与桌面/手机浏览器验收须由服务器运行完成。

仍未实现：强隔离多租户、持久 worker 队列与失败自动续跑、完整大日志无损归档、CI/PR review 自动修复闭环、TeamAI 原生协议和完整 ShowMe 原型编辑器。当前范围和测试结果见 [STATUS.md](STATUS.md)。
