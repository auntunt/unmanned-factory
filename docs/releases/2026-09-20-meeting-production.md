2. 输入：“请按公司会议规范整理附件，并调用挂靠的纪要编译器生成 Markdown 和 HTML。缺失项写待确认，单方表述不能写成双方共识。生成后读取文件核对。”
3. 在生成结果卡片下载 minutes.md、minutes.html 和 validation.json。
4. 有误直接在原对话提出修改。新产物与旧产物保留，交付前确认下载的是最后一次生成结果。
