# 项目维护与运维入口

项目概览固定展示工作入口，六环继续组织过程与成果。新增修复 Bug、启动排错、部署准备和依赖维护四类工作；用户只需补充具体问题。

入口使用既有 POST /api/v2/runs，后端 operation 白名单编译版本化工作说明，保留项目权限、能力挂载、自主策略与独立验收。默认 general 保持旧接口行为。source 中记录 operation 和 operation_version。

Bug 修复要求复现、定位根因、检查受影响调用、补回归并提供证据。运维工作使用执行器现有工具与已配置连接；部署准备不等于已上线，未连接目标时必须明确未部署。此版本没有新增定时巡检、服务器凭据管理或未经配置的远程运维执行器。

同一页面对相同内容重试沿用 idempotency_key；后端按用户和项目隔离，以事务去重，只对新运行派发规划。相同 key 改变内容返回 409。刷新页面后重新提交属于新操作；已有失败任务应从原运行接续，保留会话和成果。
