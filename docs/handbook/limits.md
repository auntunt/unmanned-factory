# 已知边界与未完成能力

本页用于避免把设计文档、演练和代码存在误当生产保证。每次版本升级都应重新核对。

## 当前已实现但有条件

- 单协调器持久队列和持续任务检查点；不是多节点高可用调度系统
- 部分检查进度持久化与身份复核；检查命令仍可能重复执行
- SDK 子进程、会话接续、有限临时错误重试；不承诺无限运行或零成本重试
- 用户会话、CSRF、成员项目授权、只读组织视图；不代表企业完整治理与合规认证
- 成果快照、运行导出、静态预览和 GitHub 发布接口；不代表已合并、部署或安装验收
- 项目运行预算和用量记录；最终账户账单来自网关，未知用量与并行调用有边界

## 明确不能声称已经具备

| 事项 | 现状 |
| --- | --- |
| 自动跨库跨文件一致备份与一键灾难恢复 | 本书提供维护规程与局部数据库快照工具 |
| 通用数据库降级与跨路径迁移 | 需逐版本、逐现场验证 |
| 所有检查或外部动作 exactly-once | 没有这种通用保证 |
| 多进程共享一套控制库横向扩容 | 单写者锁明确限制 |
| DSH 显式只读模型探针 | 当前未验证，接口返回 unsupported |
| 完整组织预算分配、审批、委派与 Agent 治理 | 多数仍在设计阶段 |
| 恢复后自动重放不明外部发布 | 有意保守，先对账 |
| 生产 SLO、灾备 RPO/RTO、容量保证 | 需要企业现场定义并实测 |
| GitBook 线上已发布 | 本次仅准备源文档、配置与本地预览 |

## 当前版本风险提醒

- `89563d5` 已覆盖有精确持久意图的提交恢复；暂存完成但意图未持久化的硬崩溃仍可能需要人工核对，见[验证记录](verification-record.md)
- 新功能可能在数据库外写资产，备份范围不能固定成两份 `.db`
- 部分旧文档仍描述历史版本或旧 CLI；维护操作优先核对同版本代码与本书来源表
- 当前云端完整隔离 CI 受主机权限阻塞，不能把局部回归通过写成完整生产验收

## 企业接入前应补的实测

按实际数据量做容量和恢复演练；确认身份、审计、保留、网络与秘密管理要求；验证真实 Provider 和代理；演练计划停机与异常中断；对完整应用做浏览器/API/数据端到端验收。以上是部署验收工作，不是本书承诺已经完成的产品能力。
