# v3 验证记录

日期：2026-09-08。环境：macOS、Python 3.14.6、Node 24、Chrome。基线与导入方式见 RUNBOOK。

## 小组管理与真实执行审查

本轮以真实执行、权限和计量为主要验收对象。管理员可创建/停用成员、分配执行项目、设置成员/项目/工作区月额度；普通成员写接口默认拒绝，仅能操作获分配项目中的本人运行。停用、改密、角色变化撤销会话，禁止移除最后一名启用管理员。读取范围仍是整个可信小组，不能作为多租户客户隔离。

调用在模型派发前原子预留 tokens；并发预留、跨月未知占用、超额后的下次派发、权限撤回、人工核对幂等与审计均有定向测试。完整输入包含供应商缓存输入，异常/部分用量保留待核对，不按零结算。统计从团队计量启用时开始，没有回填历史调用。

执行审查修复了集成检查失败后缺少有界修复、额度拒绝仍产生虚构调用事件、Codex 等到整轮结束才返回日志等问题。任务依赖、重叠文件串行、失败升级、取消和写入后中断保留现场继续沿用可信控制链。Codex 固定 medium effort，避免继承维护者个人 ultra 设置。

真实 SDK 调用发现 macOS 系统代理未被后台进程继承；在此机器为进程显式传入已有代理后，只读 Luna 探针成功。工单验收还发现保守风险规则将安全事件业务字段标为高风险、桌面插件被后台 SDK 继承等实际问题。失败验收保留原状态和未知额度，不修改成成功。

Codex 后台现以进程配置关闭应用和插件，逐项禁用 direct MCP。模型派发前验证配置、全部 MCP 分页及技能状态，验证接口缺失也拒绝派发。安装的 SDK 0.147.0 无模型验证结果为：两个 disabled MCP 条目、可用外部工具 0、54 项技能全部禁用，hooks 为空；未改动用户配置、认证文件或全局环境。

可追溯摘要见 [live-ticket-acceptance.json](validation/live-ticket-acceptance.json)。本轮真实交付时 SDK 自带命令桥接遇到中文目录路径故障，Agent 改用原生文件修改完成实现；工厂独立运行的可信检查不受影响并全部通过。普通 `thread/read` 只返回文件修改项，原始 session 日志中的 `custom_tool_call_output` 才保留了 `exec_command` 的路径乱码 panic；已按工具输出核实，未以模型自述代替诊断。此证据证明有界依赖任务能实际闭环，不代表任意规模的软件需求均能无人交付。

后续已定位并修复命令故障：shell 的 `_` 环境变量含有无效 UTF-8 字节，Rust `std::env::vars()` 因而 panic。后台剥离这个无用的 shell 记账变量及桌面进程内部连接信息，保留认证、代理和合法 Unicode 环境值；未修改用户全局配置，也没有保留此前猜测性的解释器替换。无模型 `command/exec` 先返回 0，再通过真实 Terra 随机文件读取：中文工作目录、1 次可观察命令、1 次成功结果、模型返回正确 nonce，**22,221 tokens** 已结算。证据见 [live-command-read.json](validation/live-command-read.json)。此前失败的读取探针继续保存在各自隔离目录，不视为通过。

156,649 是这次成功验收的用量，不是整个调查的总用量。之前的连接、超时、桌面工具偏移等失败尝试保存在各自 `.factory-preview/live-qualification-*` 目录；未知用量仍未知，没有据此虚构总账单。供应商未返回美元费用，不能将 token 总数换算成实际订阅 credits 或费用。

## 当前边界

初版验证只覆盖脚本演练；本轮新增了真实 SDK 请求，结果与失败记录单列在上方。尚未执行 GitHub 发布、真实云资源或飞书发送。本地演练账号与 preview 模型名称不能用于生产。

云部署、飞书汇报、外部 API 和迁移以能力模板提供，需要具体环境、授权与可观察的验收。成功交付自动提炼的是可追溯草稿材料；它尚不是经过跨客户评测的行业产品，也不是模型权重自训练。

持久调度当前支持单进程协调器。已经发生写入的中断执行保留现场，自动恢复不盲目重复发布。未知模型费用单独标记，预算约束下一次派发，不能硬限制已经在途的费用。
