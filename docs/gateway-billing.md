# webuddy 计费边界

Token 计费、账户余额和账户级额度由中转站统一管理。中转站返回的真实调用错误仍会在 webuddy 中显示。

webuddy 的项目单次运行预算是后续派发的停止线。系统在每次新的付费模型调用前核对该运行已报告的美元费用；达到预算后停止新调用，并保留已有成果和运行记录。

Claude 调用会同时收到当前剩余美元预算，并通过 Claude Agent SDK 的 `max_budget_usd` 在该次调用达到额度时停止。这个检查依赖 SDK 的用量结算时点，单次调用仍可能小幅越线。其他没有原生美元限额的供应商仍依靠 webuddy 在两次调用之间停止后续派发；已并行在途的调用也不是一个全局原子费用硬封顶。若供应商没有返回费用，页面会保留费用未知记录；账户实际扣费和额度仍以中转站为准。

运行因预算停止时，管理员先调整该项目的单次运行预算，再从暂停任务继续或创建重试。保存设置不会擅自重启已暂停的运行。页面同时保留模型配置、调用记录、成员权限和项目访问管理；任务数、并行数、执行超时和人工授权边界继续有效。

长任务默认每阶段 4 小时，可在运行配置中调整到 24 小时。执行阶段的时限覆盖全部子任务与修复。调高配置后，显式继续暂停任务会采用较长时限，同时保留原模型、并行数和任务数边界。
