# webuddy 计费边界

Token 计费、余额和额度由中转站统一管理。webuddy 不再按本地美元预算、费用缺失、成员或项目 token 配额拦截模型调用、验证、继续执行或自动交付。中转站返回的真实调用错误仍会显示。

页面保留模型配置、调用记录、成员权限和项目访问管理。任务数、并行数、执行超时和人工授权边界继续有效。

历史费用记录及旧 API 配置字段暂留用于兼容和审计，不参与任务调度，也不在操作页面提供计费设置。无需修改旧运行的冻结配置即可继续原计划。已暂停的运行不会在升级时擅自重试；用户仍可通过“回答并继续执行”恢复。

长任务默认每阶段 4 小时，可在运行配置中调整到 24 小时。执行阶段的时限覆盖全部子任务与修复。调高配置后，显式继续暂停任务会采用较长时限，同时保留原模型、并行数和任务数边界。
